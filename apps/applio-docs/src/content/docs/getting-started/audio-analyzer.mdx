Audio analysis helps you inspect recordings before conversion or training. Combine measurements with listening: a graph alone cannot tell whether a dataset is suitable.

## Inspect a recording

<Steps>

1. Open **Audio Tools** in Desktop, or **Extra** in Gradio.
2. Upload or select a recording.
3. Use the analyzer and listen while inspecting the waveform, levels, and spectrogram.
4. Save useful plots or notes, then return to the original audio to make edits.

</Steps>

Desktop has a browser-based waveform/spectrogram analyzer. Gradio's analysis output includes spectral-feature plots; the displays differ.

![Gradio audio-analysis results.](/images/audio-analyzer-result.png)

## What to look for

| Measurement | What it can show |
| --- | --- |
| Duration and channels | Recording length and mono/stereo layout |
| Waveform / peak level | Silence, sudden level changes, or suspicious flat peaks |
| RMS level | Average signal level; useful when comparing recordings |
| Spectrogram | Frequency content over time, hum, noise bands, and bandwidth limits |
| Spectral centroid, bandwidth, rolloff | Summaries of spectral distribution in the engine-generated analysis |

A high file sample rate does not prove the source contains high-frequency detail. Training preprocessing can resample a recording, but cannot recover information missing from it. Match the **training rate** to the architecture and pretrainings.

## Extract a pitch curve

Use the F0 extraction controls in **Audio Tools** to inspect how a supported pitch method tracks the voice. Unvoiced sections have no stable F0. Compare against what you hear before interpreting sudden jumps as a recording problem.

For reviewing many recordings, Desktop's [dataset review workflow](/getting-started/training/#review-recordings-in-desktop) can flag clips and prepare a separate training copy.
