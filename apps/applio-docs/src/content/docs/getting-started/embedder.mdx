An **embedder** turns audio into numerical content features used by the voice conversion model. It is separate from the speaker model and the F0 predictor.

Use the **same embedder for extraction during training and conversion during inference**. A model trained with one feature representation cannot reliably interpret a different one.

## Built-in choices

| Interface value | Model family |
| --- | --- |
| `contentvec` | ContentVec |
| `spin` | Spin |
| `spin-v2` | Spin v2 |
| `chinese-hubert-base` | Chinese HuBERT |
| `japanese-hubert-base` | Japanese HuBERT |
| `korean-hubert-base` | Korean HuBERT |
| `custom` | A compatible local embedder directory |

Choose the embedder recorded in the model metadata or specified by its author. Language alone is not a reason to change the embedder of an already trained model.

Desktop exposes the choice in conversion settings, realtime settings, and training feature extraction. Inspect models in **Models** to check available metadata.

## Custom embedders

The current loader expects a compatible local model directory. Selecting **custom** is not a promise that every Hugging Face feature-extraction network will work.

<Steps>

1. Obtain compatible weights and their matching configuration from the model publisher.
2. In Desktop training, use **Custom Embedder (.bin + .json)** to upload the files, or select an existing local directory.
3. Choose **custom** and the resulting path for feature extraction.
4. Use the same files and path for inference and realtime conversion.

</Steps>

A typical directory contains `pytorch_model.bin` and `config.json`. The architecture and feature dimensions must match what the engine and speaker model expect. Preserve these files with your experiment.

<Aside type="caution">
  Read the log if a custom path is missing or fails to load. Do not continue training under the assumption that the requested embedder was used.
</Aside>

To experiment with another embedder, extract features and train a separate model. Compare held-out conversions, rather than switching the embedder only at inference time.
