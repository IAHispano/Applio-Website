Voice conversion changes the speaker characteristics of a recording. It uses the original words, rhythm, and pitch contour; it does not generate a new performance from text. For a song, use an isolated vocal rather than the full music mix.

## Before you start

Use a short recording, for example 10-20 seconds of clear speech or an isolated vocal. Keep the original so you can compare the same phrase after each change.

<Checklist title="Ready for a first conversion" items={[

  'My inference model appears in the model list.',
  'I know the training embedder and have the matching index if one was supplied.',
  'I have a short recording with audible voice and no clipping or full music mix.',

If your model is not listed yet, finish [adding a model](/getting-started/installing-inference-models/). Complete one single-file conversion before trying a batch or tuning advanced options.

## Convert your first file

<Steps>

1. Finish engine setup and [add a voice model](/getting-started/installing-inference-models/).
2. Open **Convert Audio** and choose single-file conversion.
3. Select the model and its matching index, if available. Match the model's training embedder.
4. Upload a voice recording or choose an available input.
5. Set pitch to **0**, leave optional effects off, and select WAV or FLAC for a lossless test output. Check restored settings: Desktop remembers conversion settings per model.
6. Start conversion once and follow the job status. If it is queued, wait or check which other job is using the engine.
7. When the result is available, play the converted audio and compare the same phrase with your original. Download the result you want to keep.

</Steps>

### Check the result before changing settings

A successful first pass produces playable audio containing the original words and timing with the selected model's voice characteristics. It does not need to be your final sound yet.

- **No result or a failed job:** read the job error first. Verify setup, model compatibility, and the selected input before tuning pitch or effects.
- **Playable result with artifacts:** use [Improve a poor result](#improve-a-poor-result). Change one setting, then convert the same short clip again.
- **A result you like:** save it and note the model, embedder, pitch, and retrieval settings. Use those as your baseline.

## Batch conversion

<Steps>

1. Complete a single-file test with the model and settings you intend to use.
2. Switch to batch mode and choose the source and destination supported by your interface. Paths refer to the computer running the engine.
3. Try a small subset first. Confirm that the outputs are written where you expect and contain the correct audio.
4. Start the remaining batch and keep the interface or launch process running as required.
5. Review the job log for skipped or failed inputs, then spot-check several outputs. Save useful files outside temporary working storage.

</Steps>

If a file fails, isolate it and try it in single-file mode. This separates an input-specific problem from a model or batch configuration problem.

For CLI automation, see [batch inference](/reference/cli/#batch-conversion). For live microphone audio, use [Realtime](/getting-started/realtime/).

## Understand the main settings

<PitchExample />

| Setting | What it changes |
| --- | --- |
| **Pitch** | Shifts the extracted F0 in semitones. Positive raises it; negative lowers it. `+12` is one octave up and `-12` one octave down. Start at 0 and adjust for the recording and target range. |
| **Search Feature Ratio** | Blends retrieved index features with input features. 0 disables their influence; larger values increase it. This is not the number of neighbors searched. |
| **Volume Envelope** | Blends loudness behavior: 0 follows the original envelope more closely; 1 retains the converted envelope. |
| **Protect Voiceless Consonants** | Reduces conversion influence on unvoiced sections when pitch guidance is active. In the current engine, values below 0.5 enable protection; 0.5 disables it. Lower values provide stronger protection. |
| **Pitch extraction algorithm** | Estimates F0. Use the available choices in your release; current Desktop offers RMVPE, FCPE, CREPE, and Swift. |
| **Embedder Model** | Extracts content features. Use the same embedder used in training. |

Adjust one setting at a time and compare the same short clip. A higher retrieval ratio or stronger effect is not automatically better.

### Processing options

- **Split Audio:** processes long recordings in segments and combines the results.
- **Autotune:** adjusts the extracted pitch toward note frequencies before synthesis; strength controls the amount.
- **Proposed Pitch:** calculates an additional shift toward the configured pitch target. Avoid combining it with a large manual shift without checking the result.
- **Clean Audio:** reduces output noise. Excessive cleaning can remove detail or introduce artifacts.
- **Formant Shifting:** changes vocal resonance in the input-processing path. Start near the defaults and compare carefully.
- **Export Format:** WAV or FLAC preserves a lossless result; compressed formats are useful for sharing. Exporting at a higher rate does not restore missing input detail.
- **Inference engine / ONNX precision:** available Desktop controls depend on model and runtime support. Use the default Torch path first; read diagnostics if another engine fails.

### Effects

Enable **Post-Process** and then the effects you want. Available controls include reverb, pitch shift, delay, limiter, gain, distortion, chorus, compressor, bitcrush, and clipping.

The post-processing pitch-shift effect acts on synthesized audio; the main **Pitch** control changes F0 before synthesis. Keep effects off while diagnosing conversion quality.

## Improve a poor result

| Symptom | First checks |
| --- | --- |
| Robotic or unstable pitch | Verify embedder and speaker ID, check input quality, compare available F0 methods |
| Target voice sounds weak | Verify the matching index and try a moderate retrieval ratio |
| Harsh consonants or breaths | Try protection below 0.5 and compare |
| Distortion | Check input clipping and gain; disable effects |
| Very slow conversion | Read hardware diagnostics, stop competing GPU work, and compare a short clip without effects |
| Long file runs out of memory | Try Split Audio or shorter recordings |

<Aside type="tip">
  Save a result you like before changing more settings. Desktop working outputs are temporary; download or copy audio you want to retain.
</Aside>
