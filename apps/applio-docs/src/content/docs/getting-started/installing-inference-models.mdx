An **inference model** is a trained voice you use for conversion. It is different from an [embedder](/getting-started/embedder/) or a [G/D pretrained pair](/getting-started/pretrained/) used for training.

| File | Purpose |
| --- | --- |
| Exported `.pth` | Speaker-model weights and metadata for inference |
| Matching `.index` | Retrieved training features that can influence the converted timbre |
| `G_*.pth` / `D_*.pth` training checkpoints | Training state; not interchangeable with an inference export |

An index is optional. It may be large: its size depends on the training features. Use the index supplied for that model rather than one from an unrelated voice.

## Download or upload

<Tabs>
  <TabItem label="Desktop">

<Screenshot src={desktop.models} alt="Desktop Models workspace with Download Models selected" caption="Open Models, then Download Models, to download from a link or upload local inference weights." interfaceName="Desktop 1.0.7" />

<Steps>

1. Open **Models**, then **Download Models**.
2. Under **Download from Link**, paste a supported model link and select **Download**. For local files, use **Upload Model Files** and **Save File** for the `.pth` and `.index`.
3. Wait for the download or upload to finish, then refresh **Model Library**.
4. Select **Inspect** to check metadata, or **Use** to open conversion.

</Steps>

  </TabItem>
  <TabItem label="Gradio">

<Screenshot src={gradio.models} alt="Gradio Models workspace with model download and upload controls" caption="The Models workspace groups model downloads, uploads, and related resources." interfaceName="Gradio 3.7.1" />

<Steps>

1. Open **Models** (called **Download** in older Gradio releases).
2. Paste the model link into its download panel, or upload extracted model files using **Drop Files**.
3. Wait for completion, then refresh the model list in **Convert Audio** (or **Inference** in older releases).

</Steps>

  </TabItem>
</Tabs>

For a model archive, extract local files before uploading them individually. A downloaded web page is not a model file.

## Install files manually

Create a named folder in your active logs/models directory and put the model and index together:

Refresh the interface afterward. Desktop's active directory may be outside the installation; see [storage locations](/guides/moving-to-desktop/). Prefer the upload controls if you are unsure which folder is active.

## Check compatibility

<Checklist title="Check your model files" items={[
  'The .pth file is an inference export, not a G/D training checkpoint.',
  'The index belongs to this model, if I plan to use one.',
  'I know the model’s embedder and have checked architecture support.',
  'I will test a short recording before a long file or batch.',
]} />

Use **Inspect Model** in Desktop to read available metadata: sample rate, version, pitch guidance, embedder, vocoder, and speaker count. Match the training embedder during conversion. For a multispeaker model, choose the intended speaker ID.

Standard RVC and Applio-specific architectures have different compatibility. A `.pth` extension does not guarantee a model works in every RVC client. Desktop also exposes ONNX options; an arbitrary ONNX network is not a drop-in voice model. Start with a compatible inference `.pth` and follow the model author's format instructions.

<Aside type="note">
  Some older models lack metadata. Use the author's training settings where available, and test a short recording before processing a batch.
</Aside>

Only use models and recordings you have permission to use. The [model search page](https://applio.org/search) helps find sources; verify the files and their usage terms with the publisher.

If a model is missing or fails to load, see [troubleshooting](/getting-started/report-error/).
