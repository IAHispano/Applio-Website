Applio plugins can add tools or tabs to the **Gradio application**. A plugin written to create Gradio components does not automatically become a Desktop workspace.

<Aside type="note">
  Desktop provides native pages for conversion, separation, analysis, and training. Do not follow Gradio plugin-installation steps expecting new tabs to appear in Desktop. Check the plugin publisher's explicit Desktop support.
</Aside>

## Install in Gradio

<Steps>

1. Obtain a plugin package from its publisher, such as the [Applio Plugins repository](https://github.com/IAHispano/Applio-Plugins).
2. Read its supported Applio version and dependency instructions.
3. Open **Plugins** and upload the plugin's ZIP package.
4. Follow any restart instructions and check that its tools load.

</Steps>

For manual installation, use the lowercase path `tabs/plugins/installed` in the Gradio checkout and follow the package's expected folder structure.

![Gradio plugin installer.](/images/plugin-installer.png)

Plugins run code in your application environment. Review their source and install only packages you trust.

## Update or troubleshoot

Back up plugin-specific settings before replacing a package. Follow its update instructions rather than assuming every ZIP has the same layout.

If a plugin fails, capture its import/dependency error and check the publisher's compatibility requirements. Keep plugin failures separate from a baseline test of Applio without the extension. See [reporting issues](/getting-started/report-error/).
