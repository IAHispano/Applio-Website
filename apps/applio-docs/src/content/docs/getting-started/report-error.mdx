Start with the failed operation's message and log. Check whether the problem is setup, model loading, conversion, or audio routing before changing unrelated settings.

## Common problems

<AccordionGroup>
  <Accordion title="Engine is not ready">

Open setup, read the failed checks, and run **Install / Repair** in Desktop.

  </Accordion>
  <Accordion title="Package or GPU error">

Capture the detected hardware and PyTorch/runtime error. Repair through your interface's installer before following older package recipes.

  </Accordion>
  <Accordion title="Model missing">

Refresh the library; verify you used the active logs/models folder and an inference export.

  </Accordion>
  <Accordion title="Model will not load">

Inspect its architecture, sample rate, embedder, and file format. A D checkpoint is not an inference model.

  </Accordion>
  <Accordion title="Index error">

Try conversion without the index, then verify the matching index. Regenerate only if you have the experiment's extracted features.

  </Accordion>
  <Accordion title="Out of GPU memory">

Stop competing GPU work, reduce training batch size, disable GPU dataset caching, or try checkpointing. For long file conversion, try Split Audio.

  </Accordion>
  <Accordion title="Robotic audio">

Match the training embedder, check input quality, compare pitch methods, and test a lower retrieval ratio without effects.

  </Accordion>
  <Accordion title="Realtime drops or lags">

Increase chunk size, reduce extra context/effects, and inspect diagnostics.

  </Accordion>
  <Accordion title="No microphone or output">

Check OS permissions, selected devices, output routing, monitoring, and VAD threshold.

  </Accordion>
  <Accordion title="Job interrupted after restart">

Start the operation again. Training continuation requires compatible saved checkpoints.

  </Accordion>
  <Accordion title="Output has disappeared">

Check cleanup/retention. Download valuable audio promptly.

  </Accordion>
</AccordionGroup>

### Gradio server and CLI checks

Keep the launch process running while using Gradio. Read the address it prints; the port may differ if another service is already using it. To select a port from its Python environment:

<Command shell="bash" command={"python app.py --port 6970"} />

Inspect an inference model:

<Command shell="bash" command={"python core.py model-information --pth-path \"logs/MyVoice/MyVoice.pth\""} />

Generate an index from an experiment with extracted features:

<Command shell="bash" command={"python core.py index --model-name MyVoice --index-algorithm Auto"} />

These examples use hyphenated Click commands and flags. See [CLI reference](/reference/cli/) for environment and release differences.

## Report a reproducible bug

<Checklist title="Before you submit" items={[
  'I can reproduce the problem with a short example.',
  'I have the interface version, operating system, and GPU details.',
  'I copied the first error and the final job message.',
  'I removed private paths, tokens, and recordings from the report.',
]} />


<Steps>

1. Open **Report a Bug** in Desktop or **Report a Bug** in Gradio and collect the available diagnostics.
2. Copy the failed job's relevant log, including the first error and final message.
3. Write the steps, expected behavior, and what actually happened.
4. Include the interface, version, OS, GPU, model metadata, and any non-default settings.
5. File the issue in the appropriate repository.

</Steps>

| Problem | Issue tracker |
| --- | --- |
| Desktop interface, setup, tray, or App workflow | [Applio-App issues](https://github.com/IAHispano/Applio-App/issues) |
| Gradio or standalone Python workflow | [Applio issues](https://github.com/IAHispano/Applio/issues) |
| Documentation or public website | [Applio-Website issues](https://github.com/IAHispano/Applio-Website/issues) |

If unsure which layer failed, state your interface and include diagnostics. Redact private paths, tokens, and personal recordings before posting a public report. Community help is also available on [Discord](https://discord.gg/wY7gmqTyEV).
