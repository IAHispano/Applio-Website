TensorBoard displays metrics written by the training process. Use it alongside listening tests.

## Open the dashboard

<Steps>

1. Start training or select an experiment with saved event logs.
2. In Desktop, open **TensorBoard**; its service starts on demand. In Gradio, open its TensorBoard tab or use the repository's TensorBoard launch script.
3. Select the experiment and metrics you want to inspect.
4. Refresh if recent points have not appeared yet.

</Steps>

If the dashboard is empty, verify that training has written event logs in the active logs folder. In Desktop, inspect the service status and use its refresh/restart controls if necessary.

## Read the metrics

Training can report generator and discriminator losses, mel reconstruction, feature matching, and other terms. They measure different parts of optimization and are not directly interchangeable.

A lower total loss does not guarantee a better voice. Compare periodic exports using the same held-out speech or singing clips and the same conversion settings. Listen for articulation, pitch stability, speaker similarity, and artifacts.

<Aside type="tip">
  Record the epoch, model file, and test settings for comparisons. Keep a good checkpoint before continuing an experiment.
</Aside>

For a stalled or failing run, check the training console and **Job history** rather than relying only on TensorBoard. See [training](/getting-started/training/) for checkpoint and resume guidance.
