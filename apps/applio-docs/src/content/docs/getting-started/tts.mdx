Applio uses **Edge TTS** to synthesize speech, then can convert that audio with an RVC model. The TTS voice provides the language and delivery; the conversion model changes the voice characteristics.

## Generate speech

<Tabs>
  <TabItem label="Desktop">
    <Screenshot src={desktop.tts} alt="Desktop Text to Speech workspace" caption="Choose the text source and TTS voice, then select the conversion model before using Convert Speech." interfaceName="Desktop 1.0.7" />

<Steps>

1. Open **Text to Speech**. Choose **Write text** for a first test and enter one or two sentences. Use **Upload file** when you are ready to supply a `.txt` script.
2. Choose a voice under **TTS Voices** that matches the language of the text. Start with a neutral speed and leave optional conversion effects off.
3. Select the inference voice model, its matching index if available, and its training embedder. Check any saved model settings before starting.
4. Select **Convert Speech** once. Follow the job while speech synthesis and voice conversion run.
5. When the result appears, play the returned audio and download the version you want to keep.

</Steps>

If **Convert Speech** is unavailable, check its explanation: a model must be selected, text or a file must be provided, and the current job/model settings must finish loading.

### Check the first result

Listen to the whole short sentence. Confirm that the words and pronunciation are correct before changing the target voice settings.

- **Words or pronunciation are wrong:** correct the text or TTS voice selection. Voice conversion does not rewrite the sentence.
- **Pronunciation is correct but the voice has artifacts:** keep the sentence fixed and compare the model's pitch/retrieval settings without effects.
- **The job fails:** determine whether the log reports speech synthesis or model conversion, then use the checks below.

Download the returned result you want to keep. Save the source TTS audio separately only where your interface makes it available; not every interface exposes both stages as separate downloadable outputs.

## Work through a longer script

<Steps>

1. Get one short sentence working with the intended language, source TTS voice, and conversion model.
2. Test a paragraph containing any names, abbreviations, or unusual punctuation in the script.
3. Adjust the wording and TTS speed for pronunciation and pacing before tuning conversion effects.
4. Submit the longer text or `.txt` file. For a difficult script, work in manageable sections so a failed request does not require repeating every take.
5. Listen to the saved audio for missing phrases, pacing changes, and conversion artifacts before sharing it.

</Steps>

## Connection and voice selection

Edge TTS requires internet access. Text is sent to the remote speech service. Its available voices and service behavior can change; errors and rate limits are reported in the job log.

A custom RVC model does not add a new Edge TTS voice. Choose a source TTS voice, then convert the synthesized audio. If you prefer another synthesis service, generate the audio there and upload it to [Convert Audio](/getting-started/inference/).

## Troubleshooting

- **Synthesis fails:** check connectivity, the selected voice, and the log; try a shorter text.
- **Wrong pronunciation:** match the TTS voice's language and simplify unusual punctuation or abbreviations.
- **Conversion fails after synthesis:** check the RVC model, index, embedder, and engine setup.
- **Unnatural output:** listen to the source speech first if it is available, then compare pitch and retrieval settings without effects.

For automation and the differences between standalone and App CLI requirements, see [CLI TTS](/reference/cli/#text-to-speech).
