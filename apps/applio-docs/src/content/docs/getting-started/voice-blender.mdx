**Voice Blender** interpolates the weights of two models to create another model. It does not mix two audio tracks and does not train a new retrieval index.

## Create a blend

<Steps>

1. Open **Voice Blender** in Desktop, or the corresponding Gradio tab.
2. Enter a distinct name for the output.
3. Select or upload two compatible inference `.pth` models. ONNX files cannot be blended by this tool.
4. Start at a blend ratio of **0.5**, which gives equal weight to both models. **0** uses only the second model; **1** uses only the first.
5. Run blending, inspect the result, and test it on a short recording.

</Steps>

Models need compatible architectures, sample rates, and weight shapes. Similar-sounding voices are not necessarily compatible. Read the job log if fusion fails.

The result is saved in the active logs/models folder. Refresh the model list before using it.

## Test a blend carefully

Compare the two original models and the blend on the same recording. Move the ratio in small steps, listen, and keep notes about the source models and value. Increasing the ratio increases the contribution of the first model.

No new index is generated by blending. Start without an index, then assess whether a compatible source index improves the result. Neither source index represents a newly trained blended dataset.

<Aside type="note">
  Preserve the original models. The blended inference file does not include the full training state needed to continue either source experiment.
</Aside>
