KaraFan is an external music-separation project. You can bring its vocal output into Applio for conversion or dataset preparation. Desktop also includes an [Audio Separator](/guides/uvr/) if you prefer to work in one application.

<Aside type="note">
  The [KaraFan repository](https://github.com/Captain-FLAM/KaraFan) says the project has been on hold since June 2024. Check its current README and wiki before installing, especially on a newer system.
</Aside>

## Use KaraFan with Applio

<Steps>

1. Follow the installation guide linked from the project's README for your platform or notebook.
2. Keep its Python environment separate from Applio's environment.
3. Select your source recording, output location, and separation settings.
4. Run separation and listen to the vocal and instrumental results.
5. Save the desired vocal as lossless audio, then upload it to Applio.

</Steps>

There is no need to uninstall another project's Python environment merely to prepare audio. Follow the external tool's current dependency instructions instead of copying old installer commands.
