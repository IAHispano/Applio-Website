**Ultimate Vocal Remover (UVR)** is a powerful, free, and open-source tool for separating audio sources. It's an essential tool for creating the clean, isolated vocal tracks needed for high-quality voice model training.

## How to Install UVR

To use UVR, you'll need to install it on your local machine.

<Steps>
1.  Download the installer from the [UVR website](https://ultimatevocalremover.com/).
2.  Run the installer to set up UVR on your computer.
3.  Once installed, launch UVR and click the **wrench icon** (🔧) to open the settings.
4.  Go to the **Download Center** and download the separation models you want to use.
</Steps>

<Aside type="note">
  When you run the installer, Windows may flag it as potential malware. This is a false positive due to the installer not being signed with a commercial license. You can review the source code on their GitHub repository if you have any concerns.
</Aside>

## AMD GPU Troubleshooting for UVR

Some Linux setups using AMD GPUs can fail when the UVR plugin is installed because its dependencies may pull in `onnxruntime-gpu`, which is compiled for NVIDIA CUDA. On an AMD system, that can lead to startup crashes when Applio tries to load the plugin.

<Aside type="caution" title="Typical error">
  A common failure looks like this:

  ```text
  ImportError: libcudart.so.13: cannot open shared object file: No such file or directory
  ```

  This usually means the plugin imported the NVIDIA CUDA build of ONNX Runtime, but your system does not have the required CUDA runtime libraries.
</Aside>

### Fix

<Steps>
1.  From your Applio project root...

    Remove the CUDA-based ONNX Runtime packages from the Applio environment:
    ```bash
    . .venv/bin/activate
    pip uninstall onnxruntime onnxruntime-gpu
    ```
2.  Install the CPU build or the ROCm build instead, depending on your setup:
    ```bash
    pip install onnxruntime
    ```
    Or, for AMD ROCm support:
    ```bash
    pip install onnxruntime-rocm
    ```
3.  If you then see an error about an executable stack, clear the problematic ELF flag with `patchelf`:
    ```bash
    sudo apt install patchelf
    patchelf --clear-execstack .venv/lib/python3.12/site-packages/onnxruntime/capi/*.so
    ```
4.  Verify the package loads correctly:
    ```bash
    python -c "import onnxruntime; print('Success! Version:', onnxruntime.__version__)"
    ```
</Steps>

If Applio still fails to start after switching packages, double-check that your ROCm stack is installed correctly and that the plugin is loading from the intended virtual environment.

## How to Use UVR

<Steps>
1.  **Select Your Audio File:** Choose the audio file you want to process.
2.  **Choose an Output Path:** Select a folder where the separated audio files will be saved.
3.  **Select a Model:** Choose the separation model you want to use. Different models are optimized for different tasks.
4.  **Click Convert:** Click the **Convert** button to start the separation process.
</Steps>
