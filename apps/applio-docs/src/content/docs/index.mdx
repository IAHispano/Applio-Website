Applio converts a recording into another voice while retaining the words and performance. You can convert files, change your microphone voice live, generate speech from text, and train models from voice recordings.

## Choose your interface

| Choose by | Applio Desktop | Applio with Gradio |
| --- | --- | --- |
| Interface | A desktop window with a sidebar and job history | A browser interface organized into tabs |
| Setup | Download a build and run **Install / Repair** | On Windows, download the [compiled package](https://huggingface.co/IAHispano/Applio/tree/main/Compiled/Windows); source installation is also available |
| Use it for | Local conversion, realtime audio, and training | Existing Gradio workflows, Python development, and cloud notebooks |
| Source | [Applio-App](https://github.com/IAHispano/Applio-App) | [Applio](https://github.com/IAHispano/Applio) |

Both use the Applio voice conversion engine. Their interfaces, installation steps, and release versions differ. These docs identify Desktop and Gradio instructions where they differ.

## Your first conversion

<Steps>

1. [Install Applio](/getting-started/installation/) and finish engine setup.
2. [Add a voice model](/getting-started/installing-inference-models/): an exported `.pth` and its matching `.index`, if supplied.
3. Open **Convert Audio** in Desktop or **Inference** in Gradio. Upload a short voice recording.
4. Select the model, match its embedder, and convert. Listen before adjusting settings.

</Steps>

For a song, [separate the vocal](/guides/uvr/) first, convert it, then mix it back with the instrumental in an audio editor.

## Before you begin

Speed and memory requirements depend on your hardware and model. Training needs substantially more compute than file conversion. Check setup diagnostics rather than assuming every GPU supports the same features.

Use recordings and models you have permission to use, and follow the [Terms of Use](/tos/). If something fails, start with [troubleshooting](/getting-started/report-error/).
