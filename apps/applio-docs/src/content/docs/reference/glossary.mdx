## Models and features

| Term | Meaning |
| --- | --- |
| **RVC** | Retrieval-based voice conversion: synthesis from input content/pitch features with optional retrieved training features |
| **Inference** | Using a trained model to convert audio |
| **Embedder** | Network that extracts content features; match it between training and inference |
| **ContentVec / HuBERT / Spin** | Model families used for feature extraction |
| **F0** | Fundamental frequency, representing voiced pitch |
| **RMVPE / FCPE / CREPE / Swift** | Pitch predictors available in supported workflows; choices vary by interface/release |
| **Speaker ID** | Selects a speaker within a multispeaker model |
| **Index** | FAISS retrieval data built from training features |
| **Search Feature Ratio** | Blend coefficient for retrieved and source features, not the neighbor count |
| **KMeans** | Clustering used to reduce feature vectors before FAISS index construction |
| **Timbre** | Voice character distinct from pitch and loudness |
| **Vocoder** | Decoder that synthesizes audio from model features |
| **HiFi-GAN / MRF HiFi-GAN / RefineGAN** | Vocoder options whose architectures and weights are not interchangeable |

## Training and files

| Term | Meaning |
| --- | --- |
| **Dataset** | Recordings used to train the voice model |
| **GAN** | Generator/discriminator training framework |
| **Generator (G)** | Network that synthesizes audio |
| **Discriminator (D)** | Network used to distinguish real from generated audio during training |
| **Pretrained pair** | Compatible G/D starting weights for a new experiment |
| **Checkpoint** | Saved training state; preserve compatible G/D checkpoints to resume |
| **Inference export** | Generator weights and configuration packaged for conversion |
| **PTH** | PyTorch file extension; different checkpoint schemas share it |
| **Epoch** | One pass through the training dataset |
| **Step** | One optimization update for a batch |
| **Batch size** | Number of samples processed together; constrained by memory |
| **VRAM** | GPU memory used by models, data, and intermediate computations |
| **Checkpointing** | Recomputes intermediate values during training to reduce memory use |
| **Overfitting** | Learning the training examples too specifically, reducing performance on new recordings |
| **TensorBoard** | Displays training metrics; loss alone is not a voice-quality score |

## Audio and controls

| Term | Meaning |
| --- | --- |
| **Sample rate** | Samples per second; analysis and synthesis can use different rates |
| **Spectrogram** | Frequency content over time |
| **Mel spectrogram** | Frequency representation used in training reconstruction losses |
| **RMS** | A measure of average signal level |
| **Pitch** | Perceived frequency; the main conversion control shifts F0 in semitones |
| **Autotune** | Adjusts extracted F0 toward note frequencies before synthesis |
| **Formant** | Resonance contributing to vowel and voice character |
| **Quefrency / Timbre controls** | Parameters used by the formant-shifting operation |
| **Protect** | Retains more original features in unvoiced regions; 0.5 disables current file-path protection |
| **Volume envelope** | Loudness variation over time |
| **Split Audio** | Processes a long file in segments and combines the result |
| **TTS** | Text-to-speech; Applio uses Edge TTS with optional subsequent conversion |
| **WAV / FLAC** | Formats commonly used to retain lossless audio |
| **MP3 / OGG / M4A** | Supported export choices; encoding and playback support depend on the format/runtime |
| **Gain / limiter / compressor** | Level and dynamic-range controls |
| **Reverb / delay / chorus** | Time-based effects |
| **Distortion / clipping / bitcrush** | Effects that alter the waveform or its resolution |

## Realtime and Desktop

| Term | Meaning |
| --- | --- |
| **Chunk size** | Amount of audio processed per realtime block |
| **Crossfade** | Overlap blending used to join audio blocks smoothly |
| **Extra context** | Past audio included when processing a new block |
| **VAD** | Voice activity detection/handling |
| **Passthrough** | Unconverted microphone audio |
| **Virtual audio device** | Routes output from one app into another app's input |
| **AudioWorklet** | Browser audio-processing component used by Desktop |
| **Job** | Tracked operation with status, logs, and possible outputs |
| **Bridge Mode** | Approved browser access to a running Desktop session through a tunnel |
| **Install / Repair** | Desktop setup workflow for its engine environment |
